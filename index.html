用 CodeWave
搭建你的开发者社区

一套干净、现代的 PHP 论坛系统。开箱即用的发帖、积分、通知、后台与安全防护，让每一段代码、每一次讨论都被看见。

PHP 8.1+原生 MVC，零重型框架
9+核心社区功能模块
MIT开源可自由使用
Features

一站式的社区能力

从内容创作到社区治理，论坛需要的基础能力都已就绪。

📝

帖子与评论

Markdown 编辑器、实时预览、图片上传，支持标签与板块分类。

👤

用户体系

注册登录、邮箱验证、个人主页、积分、等级、勋章、关注与粉丝。

💬

内容互动

点赞、收藏、关注，互动自动触发站内通知与邮件通知。

🔔

消息通知

回复、点赞、收藏、关注、认证、Bug 反馈状态集中提醒。

🛡️

社区治理

审核、举报、封禁、申诉、社区规范与 Bug 反馈工单。

⚙️

后台管理

仪表盘、内容审核、用户与板块管理、系统设置、日志查看。

🔐

安全稳定

CSRF 防护、登录限流、CSP 响应头、SQL 事务、日志脱敏。

🚀

部署简单

内置安装向导，宝塔/Nginx 一行伪静态即可上线。

Deploy

三步上线

1

上传代码

整体上传服务器，运行目录设为 /public。

2

配置伪静态

Nginx 仅需一行 try_files 重写规则。

3

运行安装向导

访问 /install/，按步骤填库即可完成。
