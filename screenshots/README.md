# 截图放置说明

将你本地的界面截图按下面文件名放进本目录，展示页即可正常显示。
（支持 .png，若用 .jpg 请同步修改 index.html 中的图片后缀。）

| 文件名 | 对应界面 |
|---|---|
| home.png | 首页帖子流 |
| post-detail.png | 帖子详情 |
| editor.png | 发布编辑器 |
| my-posts.png | 我的帖子 |
| tags.png | 标签广场 |
| profile.png | 用户主页 |
| notifications.png | 消息通知 |
| categories.png | 全部板块 |
| bug-feedback.png | Bug 反馈 |
